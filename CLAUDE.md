# CLAUDE.md — Copywriting Repository Guide

Ini adalah project **template copywriting Canva** untuk pasar global.
Baca seluruh dokumen ini sebelum mengerjakan tugas apapun di repository ini.

---

## Dokumen PRD & Framework

Selalu jadikan 3 file berikut sebagai **pedoman utama** sebelum membuat atau mengedit konten:

| File | Isi |
|---|---|
| `FRAMEWORK-Copywriting.md` | Alur kerja, formula judul, story arc, tipe halaman, sistem kolom, tone, aturan bahasa |
| `FRAMEWORK-Canva-Guide.md` | Standar konten Canva: copy requirements, placeholder, lorem ipsum, teknis print/digital |
| `FRAMEWORK-Metadata-Guide.md` | Formula title & keyword untuk searchability di Canva marketplace |

## Aturan Kritis yang Wajib Dipatuhi

### Struktur Halaman
- Formula judul: `[Color] + [Style] + [Subject] + [Category]`
- 10-page formula: `Cover → Opener → Context → Core A → Core B → Core C → Engagement → Emotional Peak → Closing → Back Cover`
- Opener & Emotional/Reflective wajib ada di setiap presentasi
- Aturan kolom: halaman pertama & terakhir selalu 1 kolom; tidak boleh 2 halaman 1-kolom berturut-turut di tengah

**Nama bisnis** (untuk organisasi, venue, tim):

**3 aturan nama yang tidak boleh dilanggar:**
1. **Orang vs Bisnis** — jangan pakai nama bisnis untuk merujuk individu/person, dan sebaliknya
2. **Konsistensi konteks** — nama bisnis yang muncul sebagai venue/lokasi harus sudah diestablish di Opener file tersebut. Jangan inject nama bisnis baru mid-content
3. **Paralel struktur** — di halaman Profile/Spotlight dengan personal role labels (The Mentor, The Helper, dll.), semua kolom harus pakai nama orang

### Copywriting
- Gunakan **Simple English** — relevan secara global
- **60% Rule** — sisakan 40% ruang kosong dalam text box
- **Active Voice Only** — Celebrate, Honor, Share, Join, Create
- **No Religion, Politics, Brand Names** (Instagram → "Social Media")
- Gunakan placeholder instruksional: `[Type your message here]`

### Standar Canva Review
- Hindari tone akademis/kaku — gunakan inspiratif, celebratory, warm
- Hindari diksi: Lesson Plan, Curriculum, Syllabus, Semester
- Gunakan: Activity, Our Journey, Let's Explore
